# GPS Coordinates 📍

Shows your location in every common format, live, and copies any of them with one tap:
DD, DD with N/S/E/W, DMS, DDM, UTM, MGRS, Web Mercator, Maidenhead locator,
Plus Code, Geohash, Google Maps / Geo URI / OpenStreetMap links, altitude, accuracy, fix time.
"Copy all" puts every format on the clipboard. Works fully offline (no INTERNET permission).

Brought to you By: Black Falcon 🦅

## Build
Push to GitHub -> Actions -> "Build APK" -> download `GpsCoordinates-APK`.
Local: `gradle assembleDebug` (JDK 17, Gradle 8.7+).
